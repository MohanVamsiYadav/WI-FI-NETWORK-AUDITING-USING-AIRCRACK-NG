🟢 Wi-Fi Network Auditing using Aircrack-ng

Cybersecurity Project

Bombothula Mohan Vamsi Yadav

🔐 Project Overview

This project demonstrates the basic process of performing a Wi-Fi security audit using Kali Linux and the Aircrack-ng toolset in an authorized laboratory environment.

The project focuses on wireless monitoring, network scanning, WPA/WPA2 authentication, targeted packet capture, handshake capture, and controlled password-strength testing.

🎯 Objectives

  • Check the Wi-Fi adapter
  • Identify the wireless interface
  • Enable monitor mode
  • Scan wireless networks
  • Identify the authorized test network
  • Observe wireless information
  • Capture authorized authentication data
  • Perform controlled password-strength testing
  • Understand Wi-Fi security best practices

🛠️ Tools Used

  • Kali Linux
  • Aircrack-ng
  • airmon-ng
  • airodump-ng
  • iwconfig
  • ip link
  • TP-Link 802.11ac USB Wi-Fi Adapter

📡 Test Environment

SSID: TP-Link_6922

Security: WPA2

Cipher: CCMP

Authentication: PSK

Wireless Interface: wlan0

⚙️ Methodology

  1. Check the Wi-Fi adapter using iwconfig.
  2. Verify the wireless interface using ip link.
  3. Check adapter information using airmon-ng.
  4. Enable monitor mode.
  5. Scan available wireless networks.
  6. Identify the authorized test access point.
  7. Perform targeted packet capture.
  8. Observe the controlled client.
  9. Capture WPA/WPA2 authentication data.
  10. Perform a controlled password-strength test.

💻 Commands Used

iwconfig ip link sudo airmon-ng sudo airmon-ng start wlan0 sudo airodump-ng wlan0

📊 Results

  • Wi-Fi adapter detected successfully.
  • wlan0 interface was available.
  • Monitor mode was enabled.
  • Authorized test network was identified.
  • Targeted capture was performed.
  • WPA handshake evidence was captured.
  • Aircrack-ng password-candidate testing was performed.

🛡️ Security Recommendations

  • Use WPA3 when supported.
  • Use a long and unique Wi-Fi password.
  • Keep router software updated.
  • Change the default router administrator password.
  • Disable WPS when it is not required.
  • Use a separate guest network.
  • Perform security testing only with permission.
